## 0.3.0

Feature release since 0.2.0: album art in the player bar, missing-file detection for playlists, and opening audio files straight from the file manager with a single running instance.

### Added

#### Open files from the file manager
- Robsong registers itself for MP3, FLAC, WAV and OGG files (`.desktop` MimeType, `Exec=robsong %F`), so files can be opened via **Open With** or set as the default player
- A single file opens a compact mini player with **+ Library** and **Expand** buttons
- Several files (or a folder) open the full window with the files in a temporary **Play Now** playlist, from which they can be added to the Library
- Single-instance mode: if Robsong is already running, newly opened files are handed to the existing window instead of starting a second copy

#### Playlists
- Rescan playlists for missing files, with results shown in a framed, scrollable list and a track count
- Playback skips missing tracks automatically and shows a "not found" toast

#### Player bar
- Embedded album cover shown in the player bar, kept square and centred

### Fixed
- Fail fast with a clear error when the library store cannot be opened at startup
- Cap the single-instance socket message size and hand off to a running instance before scanning files
- Tidy Play Now edge cases (empty input, closing the mini player)

### Upgrade notes
1. `.deb` / `.rpm` packages now run `update-desktop-database` on install and removal so the file associations take effect immediately
