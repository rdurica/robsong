## 0.2.0

Feature release since 0.1.0: richer track UI controls, artist-aware search, and playlist lookup improvements.

### Added

#### Playback & volume
- Clickable mute toggle on the volume icon
- Persist volume and mute state across app restarts

#### Tracks & playlists
- Track Properties dialog from the context menu
- Playlist search matches artist as well as title (case-insensitive)
- PlaylistsContaining lookup by track path (for Properties / related UI)

### Changed
- Split the UI into concern-focused files and unify audio decode / supported extensions across audio and library layers
- Updated app logo

### Documentation
- Document prebuilt downloads from GitHub Releases in the README
- Add Goal section to the README

**Full Changelog**: https://github.com/rdurica/robsong/compare/0.1.0...0.2.0
