## 0.1.0

Initial public release of Robsong — a lightweight Fyne desktop music player for local files on Linux (amd64).

### Added

#### Playback
- Play local **MP3**, **FLAC**, **WAV**, and **OGG Vorbis** tracks (codecs bundled; no ffmpeg)
- Transport controls: play/pause, previous/next, seek, and volume
- Spectrum visualizer in the bottom bar

#### Library & playlists
- Persistent library and user playlists in SQLite (`~/.config/robsong/library.db`)
- Import individual files or entire folders
- Drag-to-reorder tracks (persisted)
- Track search and context actions (play, add to playlist, delete)

#### Packaging
- Linux distribution artifacts: stripped binary, `tar.gz` (bin + desktop entry + icon), RPM, and DEB

### Upgrade notes

1. Requires a desktop Linux environment with OpenGL, X11/Wayland, and ALSA libraries (usually already installed).
2. OGG support is **Vorbis only** (not Opus).
3. Artifacts are built on Ubuntu runners; they target common amd64 desktops (Fedora and Debian-family).
